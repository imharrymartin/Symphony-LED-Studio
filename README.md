## ✨ Key Features

- 🎛️ **Pro Studio Workstation UI**: Modern, human-designed DAW interface with 4 built-in theme schemes (*Obsidian Studio*, *Nordic Midnight*, *OLED Cinema*, *Cyber Studio*).
- 🎵 **WASAPI Loopback Audio Reactivity**: High-performance real-time FFT frequency breakdown (RMS, Bass, Mid, Treble) with live VU telemetry meters.
- ✨ **Spotify Beat Sync Engine**: Locks hardware light pulses directly to song beat structures, section hue changes (verse/chorus/bridge), and live Spotify analysis.
- 📺 **Screen Reactivity**: High-speed desktop screen dominant color extraction (MSS) with optional volume audio multiplication.
- 🎬 **Studio Light Arranger DAW**: Multi-track timeline sequencer for custom light shows, canvas waveform viewer, SVG automation curves, snap grid, and live launchpad keys.
- ⌨️ **System-Wide PC Hotkeys**: OS-level hotkey hooks to trigger colors, step sequences, and arrangements seamlessly from any game or application.
- 💡 **Smart Bulb Bridge**: Automated connectivity, status polling, and retry mechanisms for Flux LED / WiFi smart bulbs.

## ⚡ Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/imharrymartin/Symphony-LED-Studio.git
cd Symphony-LED-Studio
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Launch the Application
- **Option A**: Double-click `Symphony.bat` (or `Symphony.pyw`).
- **Option B**: Run via command line:
  ```bash
  python desktop_app.py
  ```
